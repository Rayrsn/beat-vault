# RAYR BEATS // Master Modernization Plan

## Overview

This multi-step plan outlines the full transition of **Rayr Beats** from a legacy WordPress site to a **high-impact, modern, industrial brutalist web application**.

---

## Plan Structure & Step-by-Step Documents

1. [01-site-audit-and-architecture.md](file:///home/rayr/Desktop/htdocs-rayr.cf/plan/01-site-audit-and-architecture.md)
   - Comprehensive audit of current beat packs (Beat Pack X, Special, 8, 7, 6, 5, 4, 3, beats, new-beats), `.key` stream protection files, HLS stream URLs (`rayrsn.me`), and legacy WordPress bloat.

2. [02-brutalist-design-system.md](file:///home/rayr/Desktop/htdocs-rayr.cf/plan/02-brutalist-design-system.md)
   - Industrial Brutalist visual design identity: matte void backdrops, exposed grid borders, impact typography (`Syne`, `Bebas Neue`, `Space Grotesk`, `JetBrains Mono`), neon acid highlights, scroll-driven parallax, 3D tilt effects, and View Transitions API.

3. [03-audio-engine-and-data-migration.md](file:///home/rayr/Desktop/htdocs-rayr.cf/plan/03-audio-engine-and-data-migration.md)
   - Structured JSON manifest schema (`beats-manifest.json`) for all tracks, Web Audio API engine integration with HLS.js streaming, canvas spectrum visualizer, and keyboard shortcuts.

4. [04-modern-frontend-implementation.md](file:///home/rayr/Desktop/htdocs-rayr.cf/plan/04-modern-frontend-implementation.md)
   - Modular frontend implementation blueprint: Hero section with marquee, real-time BPM/Key/Tag filtering, track card grid with canvas visualizer, sticky bottom audio player, queue drawer, and contact/licensing section.

5. [05-deployment-and-optimization.md](file:///home/rayr/Desktop/htdocs-rayr.cf/plan/05-deployment-and-optimization.md)
   - WordPress decommissioning, SEO & social OpenGraph integration, Core Web Vitals optimization (< 1s LCP, 0 CLS), and server static rewrite rules.
